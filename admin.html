How it works

All content lives in Supabase — it survives redeploys forever. Clicking Publish calls a Netlify function which writes every table to Supabase instantly. The public site and all blog post pages fetch directly from Supabase on every load — no redeployment needed for any content change.

Step 1 — Supabase credentials (browser only)

Get these from supabase.com/dashboard → your project → Settings → API.

e.g. https://abcdefghijklm.supabase.co

Also paste these values into index.html where it says %%SUPABASE_URL%% and %%SUPABASE_ANON_KEY%%, then git commit && git push so the public site reads from Supabase too.

Step 2 — Netlify environment variables
VariableValue
SUPABASE_URLSame project URL as above
SUPABASE_SERVICE_KEYSupabase → Settings → API → service_role secret (keep private)
ADMIN_SECRETAny strong secret you invent — paste it below too
Step 3 — Admin Secret
Must match the ADMIN_SECRET Netlify env var. Stored only in your browser.
Step 4 — Run the SQL schema

Go to Supabase → SQL Editor → New query, paste the contents of supabase-schema.sql from your repo, and click Run. This creates all tables, seeds default data, and sets RLS policies.
